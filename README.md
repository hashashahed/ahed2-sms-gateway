# بوابة الرسائل: منصة SMS API للبيع

موقع جاهز تبيع منه خدمة **SMS API** باشتراكات شهرية. كل زبون بيسجّل، وبيربط جوال أندرويد فيه شريحة، وبيبعت رسائل من موقعه أو برنامجه عن طريق API. الرسائل بتطلع من شريحة الزبون نفسه.

```
نظام الزبون ──API──▶ موقعك (السيرفر) ──WebSocket──▶ جوال الزبون ──▶ SMS
```

## شو فيه

**للزبائن:**
- صفحة رئيسية تسويقية فيها الأسعار، بالعربي والإنجليزي.
- تسجيل ودخول، ولوحة تحكم فيها: الأجهزة وربطها بكود QR، ومفاتيح API، والرسائل الصادرة والواردة، وإرسال تجريبي، والتوثيق، والـ Webhook.
- صفحة الباقة والدفع: الزبون بيختار الباقة والمدة، وبيشوف طريقة الدفع، وبيبعت رقم العملية.

**إلك كأدمن:**
- إحصائيات: المستخدمين والمشتركين والرسائل وإيرادات الشهر.
- طلبات الدفع: قبول بكبسة (بتتفعّل الباقة لحالها) أو رفض مع سبب.
- المستخدمين: بحث، وتفعيل أي باقة يدوياً، وإيقاف حساب، وكلمة سر جديدة، وتعيين أدمن.
- الباقات: عدّل الأسعار والحدود، أو أضف باقات جديدة.
- إعدادات الموقع: الاسم، وتعليمات الدفع، ورقم واتساب، وفتح أو إغلاق التسجيل.
- رفع ملف الـ APK، والزبائن بينزّلوه من لوحتهم.

**الحماية والحدود:**
- كل زبون بيشوف أجهزته ورسائله ومفاتيحه بس.
- السيرفر بيطبّق حد الرسائل الشهري وحد الأجهزة لكل باقة.
- الباقة المدفوعة لما تنتهي، الزبون بيرجع تلقائياً للباقة المجانية.
- كلمات السر مشفّرة (scrypt)، والمفاتيح محفوظة كـ hash، وفي حماية من CSRF وتحديد لعدد المحاولات.

## المجلدات

| المجلد | شو فيه |

## تشغيل محلي للتجربة

بدك Node.js 22.13 أو أحدث.

```bash
cd server
npm install
npm start
```

افتح `http://localhost:3000` وسجّل. **أول حساب بيصير أدمن.**

## API باختصار

```bash
curl -X POST https://your-domain.com/api/v1/sms/send \
  -H "x-api-key: sk_..." -H "content-type: application/json" \
  -d '{"to": "+970599000000", "message": "مرحبا"}'
```

| Endpoint | الوظيفة |
|---|---|
| `POST /api/v1/sms/send` | إرسال (`to` رقم أو لغاية 100 رقم، `message`، واختياري `deviceId` و `simSlot`) |
| `GET /api/v1/sms/:id` | حالة رسالة |
| `GET /api/v1/sms` | قائمة الرسائل |
| `GET /api/v1/devices` | الأجهزة |
| `GET /api/v1/account` | الباقة والاستهلاك |

التوثيق الكامل، مع أمثلة JavaScript و PHP، موجود داخل لوحة التحكم تحت **التوثيق**.

## ملاحظات مهمة عن الإرسال

- أندرويد بيحدّ الإرسال لحوالي 30 رسالة كل نص ساعة لكل تطبيق. لرفع الحد على جوال الزبون:
  ```bash
  adb shell settings put global sms_outgoing_check_max_count 1000
  adb shell settings put global sms_outgoing_check_interval_ms 60000
  ```
- التطبيق بيستنى ثانيتين بين كل رسالة، عشان شركات الاتصالات ما تحسب الشريحة سبام.
- الخدمة مناسبة لرسائل الأعمال اللي الناس متوقعينها: تأكيد طلبات، رموز تحقق، تذكيرات. مش لحملات دعائية ضخمة.
